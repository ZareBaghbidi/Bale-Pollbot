# ربات نظرسنجی و مدیریت کلاس

ربات بله برای مدیریت کلاس‌ها، ساخت نظرسنجی امتیازی و متنی، دریافت پاسخ‌ها و ارسال صورتحساب پرداختی به اعضای کلاس.

## پیش‌نیازها

- Python 3.10 یا جدیدتر
- توکن ربات بله
- توکن درگاه پرداخت، اگر از قابلیت ارسال صورتحساب استفاده می‌کنید

## نصب و راه‌اندازی

از پوشهٔ پروژه این دستورها را اجرا کنید:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp app/.env.bak app/.env
```

فایل `app/.env` را باز کنید و مقدارها را وارد کنید:

```dotenv
PROVIDER_TOKEN=توکن_درگاه_پرداخت
BALE_BOT_TOKEN=توکن_ربات_بله
OWNERS=شناسه_اونر_اول,شناسه_اونر_دوم
ADMINS=شناسه_ادمین_اول,شناسه_ادمین_دوم
```

اگر هنوز ادمینی ندارید، مقدار `ADMINS` را خالی بگذارید. `OWNERS` فهرست اونرها و `ADMINS` فهرست ادمین‌های محدود است. شناسه‌ها را با ویرگول انگلیسی جدا کنید. فایل `.env` خصوصی است و نباید در Git ثبت یا در GitHub بارگذاری شود.

ربات را از ریشهٔ پروژه اجرا کنید:

```bash
python3 -m app.bot.bot
```

## نقش‌ها

- **اونر:** دسترسی کامل دارد. فهرست اونرها فقط از `OWNERS` در `app/.env` تغییر می‌کند.
- **ادمین:** فقط می‌تواند با `create_poll` نظرسنجی بسازد و با `list_classes` کلاس‌ها را ببیند. فهرست ادمین‌ها با دستورهای اونر مدیریت می‌شود.

برای دیدن راهنمای کامل دستورهای متناسب با نقش، در ربات `help` را بفرستید. اونرها با `roles` فهرست اونرها و ادمین‌ها را می‌بینند؛ برای افزودن یا حذف ادمین از `add_admin <شناسه>` و `remove_admin <شناسه>` استفاده می‌کنند.

## نظرسنجی

دستور `create_poll` را بفرستید و مراحل انتخاب نوع، کلاس و متن سؤال را طی کنید. نظرسنجی می‌تواند فوری فعال شود یا برای تاریخ شمسی زمان‌بندی شود. پس از انتخاب تاریخ، ساعت را به شکل `h:m` بفرستید؛ برای نمونه `18:05`.

اونرها می‌توانند زمان‌بندی‌های در انتظار را با `scheduled_polls` ببینند و با `cancel_scheduled <شناسه‌زمان‌بندی>` لغو کنند.

## داده‌ها و فایل‌های محلی

پایگاه دادهٔ SQLite با نام `pollbot.db` در پوشهٔ اجرای پروژه ساخته می‌شود. خروجی اکسل نظرسنجی‌ها نیز محلی تولید می‌شود. فایل‌های محیط، دیتابیس، اکسل، محیط مجازی و فایل‌های cache در `.gitignore` قرار دارند.

## پشتیبان‌گیری

برای نگهداری پاسخ‌ها و اطلاعات کلاس‌ها، هنگام خاموش‌بودن ربات از `pollbot.db` یک نسخهٔ پشتیبان امن تهیه کنید. توکن‌ها را در مخزن عمومی یا پیام‌های عمومی قرار ندهید.
